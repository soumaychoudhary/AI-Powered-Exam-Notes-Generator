# AI-Powered Exam Notes Generator

An intelligent, full-stack web application that helps students transform simple topics into highly detailed, exam-focused study material. Users can quickly fill out a form to generate structured revision guides, view their previous study history, and download their notes instantly.

## 🚀 Features

* **Smart Form Input:** Generate detailed, exam-oriented study materials based on user-defined topics and parameters.
* **Instant Dashboard:** View and read past generated notes directly inside the application.
* **PDF Downloads:** Export generated notes as formatted PDF files for offline study.
* **History Management:** Securely save and retrieve previous study sessions.

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
